# OceanVision 3D — SIH Prototype

A working prototype for a web-based interactive 3D ocean visualization platform integrating numerical model outputs and in-situ observations.

## Features

- Interactive 3D Earth/ocean scene using React Three Fiber + Three.js
- Sample in-situ stations around the Bay of Bengal
- Numerical-model sample values generated by the FastAPI backend
- Temperature, salinity and current-speed layers
- Depth control
- Station selection and model-vs-observation comparison
- 24-hour demo time series
- Simple anomaly detection
- Responsive SIH-style dashboard

## Run backend

Requires Python 3.10+.

```bash
cd backend
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Install dependencies:
```bash
pip install -r requirements.txt
```

Start:
```bash
uvicorn main:app --reload
```

Backend:
- http://127.0.0.1:8000
- API docs: http://127.0.0.1:8000/docs

## Run frontend

Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```

Open:
http://localhost:5173

## SIH demo flow

1. Rotate the globe.
2. Click a glowing station.
3. Switch Temperature / Salinity / Current speed.
4. Move the depth slider.
5. Show model vs observed values.
6. Show anomaly count.
7. Explain that the current dataset is demo data and can be replaced by real NetCDF/CSV ocean model and sensor feeds.
